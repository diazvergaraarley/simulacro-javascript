# Project Management SPA

## 📌 Description
This project is a Single Page Application (SPA) built with Vanilla JavaScript that allows internal project management for a company. It includes authentication, role-based access control, session persistence, and full CRUD operations using a simulated REST API with json-server.

The system supports two roles:
- Manager: Full access to all projects (create, edit, delete, view statistics)
- Collaborator: Can only view and update assigned projects

---

## ⚙️ Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript (ES Modules)
- Vite
- json-server
- LocalStorage API
- Fetch API
